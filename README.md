## 栈(Stack)

一种有次序的数据项集合。在栈中，数据项的加入和移除都仅发生在同一端。

* 特点为

1. **后进先出(Last in first out, LIFO)**：最新加入栈的数据项会被最先移除
2. **反转次序**：进栈和出栈的次序相反

* 相关操作

1. stack(): 创建一个空栈，不包含任何数据项
2. push(item): 将item加入栈顶，无返回值
3. pop(): 将栈顶数据项移除，并返回，栈被修改
4. peek(): 获取栈顶数据项，返回栈顶数据项但不移除，栈不被修改
5. isEmpty(): 返回栈是否为空栈
6. size(): 返回栈中有多少个数据项
